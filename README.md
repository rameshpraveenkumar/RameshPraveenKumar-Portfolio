## ✦ Local Development

To run the site locally:
```bash
# Clone the repository
git clone https://github.com/rameshpraveenkumar/RameshPraveenKumar-Portfolio.git

# Navigate to directory
cd RameshPraveenKumar-Portfolio

# Serve locally using any static HTTP server (e.g., serve, Live Server, or Python)
npx serve .
# or
python -m http.server 3000
```
